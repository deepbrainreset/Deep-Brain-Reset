# Deep Brain Reset

Deep Brain Reset is a multidisciplinary creative technology portfolio and production website combining web development, artificial intelligence, 3D, audiovisual production, and digital experiences.

## Purpose

The project presents commercial work and digital products developed under Deep Brain Reset, with an emphasis on end-to-end execution: concept, product definition, interface design, implementation, visual production, and delivery.

## Tech Stack

- React 19
- TypeScript
- Node.js / Express
- Vite
- Tailwind CSS
- Motion
- Google Gemini integration capability

## Development Approach

The site was built using an AI-assisted engineering workflow. AI coding tools are used to accelerate implementation, debugging, refactoring, and iteration, while product direction, architecture, integration, testing, visual decisions, and final delivery remain under human review and control.

## Local Development

```bash
npm install
npm run dev
```

Type checking:

```bash
npm run lint
```

Production build:

```bash
npm run build
```

## Security

Local environment files and runtime secrets are excluded from version control. Never commit production credentials.
